daily <todo>

A simple daily task manager for planning, prioritizing, and tracking your to-dos by date, with calendar navigation and priority levels.

HOW TO USE
  • Add a task — tap the + button, type your task, pick a priority
  • Add by voice — tap the mic to start speaking, tap it again to stop, review the converted text in the input field, then tap + to add it as a task
  • Set a date — use the calendar picker in the Add dialog, or the bottom-nav calendar to browse by day
  • Colored dots on the calendar show task status: pink for overdue, lavender for due today, yellow for upcoming.
  • Change language — tap the globe icon for 11 supported languages
  • Voice input — tap the mic icon and speak your task instead of typing
  • Filter and sort — use the dropdown and sort button above your task list
